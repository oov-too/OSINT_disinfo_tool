# Portable operations (core; every brief template loads this, 2026-10-22)

The briefs run unchanged on macOS, Linux and Windows (tools/platform-plan.md, Portability): every file operation goes through `ledger`, Python, or the agent harness's own file tools (Read, Write, Edit, Grep), never through a shell idiom. A shell idiom (a heredoc, `cp`, `cat`, `sed`, `grep`, `>` or `| tee`, `&&` chains, the `sqlite3` client) behaves differently or not at all under PowerShell, and an output redirect there writes UTF-16. `ledger` below is the installed command; in a project folder before installation it is `python3 ledger.py` at the project root, and `python3 tools/<tool>.py` runs the same tool directly.

| Operation | Form in the briefs | Until the `ledger` form exists | Never |
|---|---|---|---|
| Run a project tool | `ledger <layer> <tool> <arguments>` (`ledger tools` lists them) | `python3 ledger.py <layer> <tool> <arguments>` | |
| Keep the computer awake through a run (the orchestrator, before launching a workflow or any agent that outlasts its turn; tools/agent-wip.md item 9) | the Claude desktop app's keep-awake tool (request_keep_awake, until the session is idle) | macOS `caffeinate -i` for the run's length; Linux `systemd-inhibit`; Windows the power plan or `powercfg /requestsoverride` | launching a long run with sleep allowed: a sleeping computer kills the agent in flight, and a closed lid still sleeps |
| Read a whole file with line numbers | the Read tool (its numbering is the file's own: line 1 is line 1) | | `cat -n` |
| Read a line range | the Read tool with offset and limit | | `sed -n 'a,bp'` |
| Print a line range verbatim (a probe that returns the text) | `ledger file lines <path> <a>-<b>` (to build) | `python3 -c "import sys; L = open(sys.argv[1], encoding='utf-8').read().split('\n'); print('\n'.join(L[int(sys.argv[2]) - 1:int(sys.argv[3])]))" <path> <a> <b>` | `sed -n 'a,bp'` |
| Count a file's lines | `ledger file lines <path> --count` (to build) | `python3 -c "import sys; print(len(open(sys.argv[1], encoding='utf-8').read().split('\n')))" <path>` | `wc -l` |
| Copy a line range into a new file without passing it through your own output | `ledger file lines <src> <a>-<b> --out <dst>` (to build) | `python3 -c "import sys; L = open(sys.argv[1], encoding='utf-8').read().split('\n'); open(sys.argv[2], 'w', encoding='utf-8', newline='\n').write('\n'.join(L[int(sys.argv[3]) - 1:int(sys.argv[4])]) + '\n')" <src> <dst> <a> <b>` | `sed -n ... >` |

| Check a staged intake's findings size (the reader, before it marks a unit done) | `ledger extract gate --findings --wip wip/<task> --units NNN-NNN --size`: per unit the findings words, the item allowance (200 + 35 per claim, 30 per question, 20 per quotation, 25 per other item) and how it is made, the items per section and the state; over the allowance without a valid `size: over budget: <section>: <n> items over <cap> words: <reason>` head line fails gate 1 (`--budget R`: the older ratio, for archived findings only) | `python3 tools/intake_gate.py --findings --wip wip/<task> --units NNN-NNN --size` | `wc -w` against a share of the unit |
| List the held rows bearing on a narrative page's nodes that the page never cites (the unused-rows check, before the Score card and in the attacker's test 10) | `ledger narrate unused <page> --out wip/<task>/unused.md [--node N] [--cap K]` | `python3 ledger.py narrate unused <page> --out wip/<task>/unused.md` | a grep of notes or the database for each node's names |
| Find a held row by content | `ledger analyse rows "<query>" [--note <stem glob>] [--table claims\|timeline\|audit] [--json]` | | `grep` over notes |
| Find a term in a register or page | the Grep tool, case-insensitive, on the file | | `grep -i` |
| Copy a file without passing it through your own output (a unit to current-unit.md) | `ledger file copy <src> <dst>` (to build) | `python3 -c "import shutil; shutil.copyfile('<src>', '<dst>')"` | `cp`, `copy`, `Copy-Item` |
| Save a tool's printed output to a file | `ledger run --out <file> -- <layer> <tool> <arguments>` (to build) | `python3 -c "import subprocess, sys; r = subprocess.run([sys.executable, 'ledger.py', '<layer>', '<tool>', '<arg>', ...], capture_output=True, text=True, encoding='utf-8'); open('<file>', 'w', encoding='utf-8', newline='\n').write(r.stdout)"` | `>`, `\| tee` |
| Write a new file (a note part, a findings file, a TSV, a JSON report) | the Write tool, or a Python script | | a heredoc, `echo ... >` |
| Change a file in place by exact string | the Edit tool, or Python | | `sed -i` |
| Query the database | `ledger db sql "<select ...>" [--db <path>]` (to build) | `python3 -c "import sqlite3; [print(*r, sep=' \| ') for r in sqlite3.connect('<db>').execute('<select ...>')]"` | the `sqlite3` client |
| Split a file into k equal chunks | `ledger narrate narratives --sweep <page> --out <file> --chunks k` (to build) | a Python script written to `wip/<task>/split.py` and run with `python3` | `split`, `awk` |
| The verbatim check | `ledger extract verbatim <part> [--sources <dirs>]` as a call of its own after the write, never chained to it (`&&`, `;`): the check exits non-zero on a copied span of 40 or more words, and a chained call then shows as a failed write | | |

Rules that go with the table:

- Where a brief or a protocol document has to give the interim form because the `ledger` form is not built yet, the interim command is followed by the marker `(interim form; <the ledger form> to build)`, so that phase 2's follow-up finds every one by searching for `interim form;` and swaps it.

- Text you write is UTF-8 with LF line endings (the Write tool and `ledger`'s writers do this; a Python script opens files with `encoding='utf-8', newline='\n'`). Citations are line numbers and the verbatim gate matches text, so a file must read the same on every machine.
- Nothing fetched or held passes through your own output: a held text is copied by the copy operation, never re-typed by the Write tool. Quotations are the exception the forms allow, and they are copied exactly.
- A path you write into a note or a report uses forward slashes and is relative to the project root.
